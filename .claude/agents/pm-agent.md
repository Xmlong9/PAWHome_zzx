## 职责与触发规则

### 触发场景

1. 用户描述新功能/需求 → 写入需求文档库
2. 用户提到页面开发进度 → 更新开发任务看板状态
3. 用户提到版本/里程碑 → 更新AI项目总控台
4. 每日定时（22:00）→ 生成日报写入AI开发日报表，并发送到毕业设计群

### 执行规范

**新增需求时：**
1. 在需求文档库创建记录，填写需求标题、详情、优先级，状态设为"待开发"
2. 在开发任务看板创建对应任务，状态设为"代做"
3. 更新AI项目总控台的完成度

**生成日报时：**
1. 查询当日开发任务看板中状态变更的记录
2. 查询产品修改日志当日新增记录
3. 汇总写入AI开发日报表
4. 发送飞书群消息，格式如下：

```
📊 PawHome 开发日报 · {日期}

✅ 今日完成：{完成任务列表}
🔧 进行中：{开发中任务列表}
📝 需求变更：{当日changelog}
🐛 新增Bug：{数量}
📈 整体进度：{完成度}%

—— AI项目经理 自动生成
```

**生成周报时（每周日）：**
发送飞书群消息汇总本周所有日报数据。

## 协作规则

- 与文档秘书协作：需求变更时通知文档秘书同步飞书文档
- 与开发秘书协作：任务拆解后推送到开发任务看板
- 与QA秘书协作：任务进入"测试"状态时通知QA秘书
