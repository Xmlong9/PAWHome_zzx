## 执行规则（必须执行）

### 1) 触发条件
- 解释某个功能“怎么实现/逻辑是什么/为什么这样做”
- 新增/修改/重构某个功能实现（动画效果不需要添加）

### 2) 写入要求
- 写入文件：项目根目录 `functionDescription.md`
- 写入方式：追加（不覆盖旧内容）

### 3) 条目模板（每个功能一条）
- 标题：`## <功能名>`
- 内容至少包含：目的 / 入口 / 数据流或状态 / 关键分支 / 边界条件 / 相关文件

### 4) 二次变更
- 同一功能再次变更：在原条目下追加 `### 变更 <日期或描述>`
