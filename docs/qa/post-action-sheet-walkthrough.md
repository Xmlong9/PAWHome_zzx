# 帖子动作面板交互走查清单

## 页面入口
- [ ] 仅帖子详情页作者区右侧显示“…”按钮
- [ ] 点击“…”后从底部滑出面板，遮罩为 85% 黑色
- [ ] 面板圆角与高度符合规范（最大不超过屏幕 60%）

## 分享模块
- [ ] 默认加载分享对象列表（互关/关注/粉丝）
- [ ] 支持切换分组标签并筛选展示用户
- [ ] 支持多选用户并站内发送帖子分享消息
- [ ] 微信好友分享按钮可触发微信原生分享
- [ ] 朋友圈分享入口可提示用户从右上角完成分享
- [ ] 复制链接成功后显示 Toast

## 内容操作模块
- [ ] 帖子有图片时可执行批量保存到相册
- [ ] 未授权相册权限时提示并中断
- [ ] 帖主可置顶/取消置顶帖子
- [ ] 达到置顶上限时有明确错误提示
- [ ] 编辑帖子时可同时设置可见范围
- [ ] 删除帖子后成功返回上一页并刷新列表

## 动效与交互
- [ ] 面板出现/消失动画平滑（0.3s ease-in-out）
- [ ] 操作按钮点击态透明度下降（0.15s）
- [ ] 点击遮罩可关闭面板
- [ ] 各失败场景有 Toast 提示

## 埋点
- [ ] 打开面板事件上报
- [ ] 站内分享事件上报
- [ ] 微信分享与朋友圈入口事件上报
- [ ] 复制链接/保存图片/置顶操作事件上报
