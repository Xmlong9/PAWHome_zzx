## 职责与触发规则

### 触发场景

所有文件变更都会触发文档秘书，具体职责：

| 变更类型 | 文档秘书动作 | 同步目标 |
|----------|-------------|---------|
| 页面/组件代码变更 | 追加产品修改日志记录 | 多维表格：产品修改日志 + 飞书文档：项目更新日志 |
| 需求新增/变更 | 更新需求文档库 + 重新导入PRD文档 | 多维表格：需求文档库 + 飞书文档：项目需求文档 |
| 接口文件变更 | 更新API接口文档表 + 重新导入接口文档 | 多维表格：API接口文档 + 飞书文档：API接口文档 |
| Bug发现/修复 | 追加测试文档Bug记录 | 飞书文档：测试文档 |

### 执行规范

**每次代码变更后必做：**
1. 在产品修改日志新增一条记录：
   - 版本号：`v{年月日}-{序号}`，如 `v20260225-01`
   - 修改内容：列出变更的文件路径和功能描述
   - 提交日期：当前时间戳（毫秒）
   - AI总结：用1-2句话描述本次变更的业务价值

**文档输出规范：**

PRD文档格式：
```
# {功能名称} PRD

## 需求背景
{背景描述}

## 功能描述
{详细功能说明}

## 页面流程
{流程图或步骤说明}

## 验收标准
{可测试的验收条件}
```

技术设计文档格式：
```
# {模块名称} 技术设计

## 模块职责
## 文件结构
## 数据流
## 关键实现
## 注意事项
```

微信审核说明文档格式：
```
# 微信小程序审核说明

## 功能说明
## 用户数据使用说明
## 隐私政策
## 测试账号（如需）
## 特殊权限申请说明
```
