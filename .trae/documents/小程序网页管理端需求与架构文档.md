## 1. 项目概述

### 1.1 项目背景

爱宠家是一个基于微信小程序的宠物社区应用，集社区交流、商品购买、宠物服务与个人中心于一体。随着用户量和业务量的增长，需要一个功能完善的网页管理端来支持运营管理工作。

### 1.2 项目目标

- 提供直观高效的管理界面，支持日常运营工作
- 实现用户、内容、商品、服务等核心业务的管理
- 提供数据分析和统计功能，支持决策
- 确保系统安全、稳定、可扩展

### 1.3 适用范围

本文档适用于爱宠家小程序网页管理端的需求分析、设计、开发、测试和部署。

### 2.4 系统流程概览图

#### 2.4.1 用户注册登录流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant W as 微信
    participant A as 小程序
    participant B as 后端
    participant D as 数据库
    
    U->>A: 点击登录
    alt 微信登录
        A->>W: 获取code
        W-->>A: 返回code
        A->>B: 发送code
        B->>W: 验证code获取openid
        W-->>B: 返回openid
        alt 新用户
            B->>D: 创建用户记录
            D-->>B: 确认
        else 老用户
            B->>D: 查询用户信息
            D-->>B: 返回用户信息
        end
    else 手机号登录
        A->>B: 发送手机号+验证码
        B->>D: 验证验证码
        D-->>B: 验证结果
        alt 新用户
            B->>D: 创建用户记录
            D-->>B: 确认
        else 老用户
            B->>D: 查询用户信息
            D-->>B: 返回用户信息
        end
    end
    B->>B: 生成JWT Token
    B-->>A: 返回Token和用户信息
    A->>A: 保存Token
    A-->>U: 登录成功
```

```mermaid
sequenceDiagram
    participant U as 用户

    U->>A: 选择商品加入购物车
    A->>B: 添加购物车请求
    B->>D: 保存购物车项
    D-->>B: 确认

    U->>A: 选择收货地址
    U->>A: 选择支付方式
    U->>A: 提交订单
    A->>B: 创建订单请求
    B->>D: 校验库存
    D-->>B: 库存状态
    alt 库存充足
        B->>D: 创建订单记录
        B->>D: 创建订单项
        B->>D: 扣减库存
        B->>D: 清空购物车
        D-->>B: 全部确认

    else 库存不足
        B-->>A: 返回库存不足
        A-->>U: 提示库存不足
    end
```

### 4.3 接口规范

#### 4.3.1 RESTful API设计

**基础URL：** `/api/v1/admin`

**认证方式：** JWT Token，在请求头中携带：`Authorization: Bearer {token}`

**响应格式：**

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

**错误响应：**

```json
{
  "code": 400,
  "message": "错误信息",
  "data": null
}
```

### 4.6 安全策略

#### 4.6.1 认证安全

- 使用JWT进行身份认证
- Token有效期设置为2小时
- 支持Token刷新机制
- 密码使用bcrypt加密存储
- 登录失败次数限制，超过5次锁定30分钟

#### 4.6.2 权限安全

- 实现基于角色的访问控制（RBAC）
- 每个API接口进行权限验证
- 超级管理员拥有所有权限
- 权限最小化原则

#### 4.6.3 数据安全

- 敏感数据加密存储
- 使用HTTPS加密传输
- SQL注入防护（使用ORM）
- XSS攻击防护
- CSRF攻击防护

#### 4.6.4 操作安全

- 记录所有管理员操作日志
- 敏感操作需要二次确认
- 定期备份数据库
- 异常登录告警
