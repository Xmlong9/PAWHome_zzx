## 工作流

### 1) 先输出解释

- 先在对话里用清晰条目解释功能实现逻辑（入口、数据流/状态、关键分支、边界条件、相关文件）。

### 2) 再同步写入 functionDescription.md（必须）

- 写入文件：项目根目录 `functionDescription.md`
- 写入方式：追加（禁止覆盖既有内容）
- 每个功能一条，用二级标题开头：`## <功能名>`
- 内容至少包含：
  - **目的**
  - **入口**
  - **数据流/状态**
  - **关键分支**
  - **边界条件**
  - **相关文件**

### 3) 同一功能的再次变更

- 在原条目下追加：`### 变更 <日期或描述>`，说明本次变化点与影响面。
